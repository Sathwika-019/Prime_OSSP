# Linux OS Management System

## Project Overview

This project demonstrates important Linux Operating System concepts using C programs and shell scripting.

## Course Outcomes

### CO-1: System Calls and Shell
- System calls
- Linux shell scripting
- Process and system information

### CO-2: Process Management
- Process creation using fork()
- Process termination
- Process execution using exec()

### CO-3: Inter-Process Communication
- Pipes
- FIFO
- Signals

### CO-4: Memory Management
- Process memory maps
- Copy-on-Write
- /proc/self/maps

### CO-5: File Management
- File I/O
- Directory operations
- Memory-mapped files using mmap()

### CO-6: Synchronization
- POSIX threads
- Race conditions
- Mutex
- Condition variables
- Semaphores

## Tools Used

- Ubuntu Linux
- GCC Compiler
- Bash Shell
- POSIX APIs
- pthread library
